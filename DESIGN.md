# Sistema visual — SECOP II

Misma línea del ODC v2 / [awesome-design-md](https://github.com/VoltAgent/awesome-design-md): lienzo casi negro, un solo acento verde (UCundinamarca), bordes finos, tipografía Inter + JetBrains Mono.

| Variable | Valor | Uso |
| --- | --- | --- |
| `--lienzo` | `#0e0f0e` | Fondo |
| `--superficie` | `#151716` | Paneles |
| `--verde` | `#00d992` | Acento, CTA, aciertos |
| `--ambar` | `#f2c230` | Avisos |
| `--tinta` | `#f2f2f2` | Títulos |

Radio 6–8 px. Sin sombras genéricas. Movimiento corto (entrada de resultados).
